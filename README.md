# WAMEUP Landing Page

## [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) + [shadcn/ui](https://ui.shadcn.com/) + [Tailwind CSS](https://tailwindcss.com/)

WAMEUP landing page — Airbnb-inspired design system, fully responsive, dark/light mode out of the box.

## Sections

- [x] Navbar
- [x] Sidebar (mobile)
- [x] Hero
- [x] Sponsors
- [x] About
- [x] Stats
- [x] How It Works
- [x] Features
- [x] Services
- [x] Call-to-Action (CTA)
- [x] Testimonials
- [x] Team
- [x] Pricing
- [x] Newsletter
- [x] FAQ
- [x] Footer

## Features

- [x] Airbnb-inspired design (Rausch color palette, Inter font, warm dark mode)
- [x] Fully Responsive Design
- [x] Dark / Light Mode
- [x] Meta tags

## Getting Started

```bash
git clone https://github.com/wameup-com/wameup-landing.git
cd wameup-landing
npm install
npm run dev
```

## Build

```bash
npm run build
```
